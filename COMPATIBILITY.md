`prometheus.dll` is Release/x64/v143. `patcher` targets `net8.0-windows`. Fixed offsets in the patcher and DLL prevent a claim of version independence. The read-only inspector reports machine, optional-header agreement, versions, SHA256 and Authenticode status; none of these alone proves compatible hooks or complete CASC content.

Windows standalone relay and regression harness passed with MSVC 19.44.35228.0, Windows SDK 10.0.26100.0. CMake/server and process harness contain Linux paths, but no Linux build/runtime was tested. The injected client remains Windows-specific. Upstream Wine instructions were not verified.

Maintain the beta adapter as a regression reference. Future retail support must be selected by verified profile/fingerprint, not a global offset replacement. Current protocol validation intentionally matches upstream serialization. It cannot be used to infer packet compatibility with a retail client.
